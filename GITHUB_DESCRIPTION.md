## Longer Description (for GitHub repo About section)
```
Pentagon Pizza Index (PIZZINT) - A satirical cyberpunk-themed OSINT web application that monitors pizza delivery activity around the Pentagon to infer potential military operations. Built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion. Features real-time tracking, DEFCON indicators, historical timeline, and a terminal-style theory explainer. When pizza orders spike, the world holds its breath.
```
